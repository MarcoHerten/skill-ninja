## Agent skills

### Issue tracker

Issues live as GitHub issues, accessed via the `gh` CLI (this repo needs a git
remote configured before `gh` commands work). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles map 1:1 to GitHub labels of the same name. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context — one root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.
